Source waveform

Source amplitude is in robust units: (source − median) / (1.4826 × MAD). Vertical µV labels show this IC's contribution relative to its median at the strongest-loading electrode, named above each plot. Shading marks grouped event intervals: red below the sharing threshold, yellow for shared events. Red short marks identify original threshold-run peaks. A dashed vertical line marks the selected event peak.

Signed delta traces

Each time scale has its own labeled vertical range; dashed horizontal lines are ±5.
Delta = source(t + lag/2) − source(t − lag/2), robustly normalized separately for each IC and lag. Delta times are centered on the samples used to calculate each difference. Every time scale contributes to the same candidate mask.

Detection and grouping

Original threshold runs are the primary count. Shape labels describe detected waveforms; they do not filter candidates. Parenthesized counts remove entire grouped events classified as shared at their peak. The adjusted run count sums threshold runs within the remaining groups; it does not classify each original run separately. Grouped intervals remain available for waveform navigation and shared-event context.

Use ← / → to step through grouped events, or click the whole-recording view to inspect quieter stretches. Selecting an event expands the view if needed to include the full interval.
